Twans Survives College 
Description: This is a text based python game where you are Twan a college student in a world where the job market is really bad and you need an internship to get to possibility of getting a job. Set in Utah  in a college called lebronjames college of Jawns in a difficult situation he is very poor but thankfully you been given a large scholarship that pay for all of your college expenses but you need to keep your gpa above or at 3.0, You start at 4.0 gpa you will drop out and your head will explode, But another issue is you are a Chemistry major and the work load is a lot and it is very stressful so you must manage that… If your stress get to high above 100 you will die because you head can also explode, But you are lonely if you peer respect gets below 0 you will not explode but you will die from loneliness… To win survive and get an internship before 8th semester and keep gpa good.

Features 
Decision based game 
Player stats 
Random events that can affect the outcome of your story
Multipe game over conldidtions 

How to run 
Using rich so to install use "pip install rich" 

How to play 
It is turn based and you will be giving options and based on that your stats can change (Gpa, Stress, Readiness)
